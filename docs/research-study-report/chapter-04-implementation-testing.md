# Chapter Four: System Implementation, Testing and Presentation

## 4.1 Introduction
This chapter presents the implementation of SMNS, the major modules available in the system, and the testing carried out to validate system functionality.

## 4.2 System Implementation
The Seminary Management and Results System was implemented as a web-based application with role-based access for different categories of users.

## 4.3 Major System Modules
### 4.3.1 Administration Module
Supports management of students, academic years, semesters, courses, approvals, dashboards, and reports.

### 4.3.2 Student Module
Supports login, profile access, course registration, result viewing, transcript access, invoice review, payment reference generation, and notifications.

### 4.3.3 Lecturer Module
Supports academic interactions such as result handling and course-related responsibilities where configured.

### 4.3.4 Finance Module
Supports invoice management, payment tracking, balances, and finance communication features.

### 4.3.5 Results and Transcript Module
Supports result entry, grading, GPA generation, transcript preparation, and academic standing records.

### 4.3.6 Reporting and Notification Module
Supports alerts, activity tracking, summaries, and institutional monitoring.
