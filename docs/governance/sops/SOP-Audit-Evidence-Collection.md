# SOP: Audit Evidence Collection

## 1. Purpose

Standardize how governance control evidence is collected and presented for audits.

## 2. Control Scope

- Data governance policy evidence
- Roles/responsibilities and access evidence
- Retention/archival evidence
- Change-management evidence

## 3. Steps

1. Open `mapping/Control-to-System-Mapping.md`.
2. For each control, collect listed evidence artifact(s).
3. Record each evidence item in `templates/Audit-Evidence-Register.csv`.
4. Validate artifact date range covers audit period.
5. Mark owner sign-off and review completion date.

## 4. Minimum Evidence Set

1. Policy documents (current versions)
2. Role/access review outputs
3. Retention and purge logs
4. Backup and restore test records
5. Change request and approval records
6. Workflow audit/activity logs

## 5. Output

An audit package folder with indexed evidence IDs matching the evidence register.
