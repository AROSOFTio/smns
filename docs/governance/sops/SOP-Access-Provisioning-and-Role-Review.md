# SOP: Access Provisioning and Role Review

## 1. Purpose

Provision, modify, and review user access with traceability and least privilege.

## 2. Scope

All SMNS user roles (`student`, `lecturer`, `finance`, `admin`) and privileged module access.

## 3. Inputs

- Access request ticket/reference
- User identity and role justification
- Approver details

## 4. Procedure

1. Validate requester identity and business need.
2. Confirm requested role aligns with approved responsibilities.
3. Create or modify account in system with minimum required privileges.
4. Record who approved and who executed the change.
5. Notify requester and data owner.
6. Store evidence in access review log template.

## 5. Quarterly Access Review

1. Export active users by role.
2. Academic owner validates academic-role accounts.
3. Finance owner validates finance-role accounts.
4. IT validates admin privileges and dormant accounts.
5. Remove or disable excess/unneeded access.
6. Save signed review output.

## 6. Evidence

- Completed `templates/Access-Review-Log.csv`
- Approval email/ticket ID
- Change reference (if needed)
