# SMNS Draw.io Diagrams

This folder contains editable `draw.io` diagram files for the current SMNS system.

Files:

- `smns-dfd-level-0.drawio`
- `smns-dfd-level-1.drawio`
- `smns-dfd-level-2-overview.drawio`
- `smns-dfd-level-2-academic.drawio`
- `smns-dfd-level-2-results.drawio`
- `smns-dfd-level-2-finance.drawio`
- `smns-dfd-level-2-transcript.drawio`
- `smns-simple-dfd.drawio`
- `smns-simple-erd.drawio`
- `smns-simple-flowchart.drawio`
- `smns-use-case-diagram-simple.drawio`
- `smns-class-diagram-simple.drawio`
- `smns-sequence-diagram-simple.drawio`
- `smns-erd-full.drawio`

Open them in:

- draw.io desktop
- diagrams.net in the browser
- VS Code draw.io extension

Recommended DFD order:

1. `smns-dfd-level-0.drawio` for the context diagram
2. `smns-dfd-level-1.drawio` for the main process breakdown
3. `smns-dfd-level-2-overview.drawio` for one combined Level 2 view
4. The individual Level 2 files for process-specific report sections

The `smns-simple-*` files are the lighter report and exam versions.
